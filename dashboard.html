⚙️ Setup Guide

5 steps to fully automated LinkedIn fame

🚀 One-Time Setup (15 minutes)
✓
Step 1: Get your API Keys (Free)
• NewsAPI: Sign up at newsapi.org — Free tier: 100 req/day ✅
• Claude API: Get key at console.anthropic.com
• LinkedIn: Go to linkedin.com/developers → Create App → OAuth2 → get Access Token
• GitHub: Your GitHub account (already have it!)
2
Step 2: Fork the GitHub Repository
Fork this repo to your GitHub: github.com/YOUR_USERNAME/linkedin-ai-news

Then go to Settings → Secrets → Actions and add:
• LINKEDIN_ACCESS_TOKEN — Your LinkedIn OAuth token
• LINKEDIN_PERSON_ID — Your LinkedIn URN (e.g., urn:li:person:xxxxx)
• ANTHROPIC_API_KEY — Claude API key
• NEWS_API_KEY — NewsAPI key
3
Step 3: Upload the Automation Scripts
Upload these files (download below) to your forked repo:
• .github/workflows/post-ai-news.yml — GitHub Actions scheduler
• scripts/fetch_news.py — News fetcher
• scripts/generate_post.py — Claude post generator
• scripts/post_linkedin.py — LinkedIn poster
• scripts/run_all.sh — Master runner
4
Step 4: Enable GitHub Actions
In your repo: Actions tab → Enable workflows
The cron is set to 00 30 0 * * * (00:30 UTC = 6:00 AM IST)
Test it by clicking "Run workflow" manually first!
5
Step 5: LinkedIn Token Refresh (Monthly)
LinkedIn access tokens expire every 60 days. Set a calendar reminder to refresh via:
https://www.linkedin.com/developers/tools/oauth/token-generator
Update the secret in GitHub → Settings → Secrets → LINKEDIN_ACCESS_TOKEN
